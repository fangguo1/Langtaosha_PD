# LTS Search 2.0 Design System

## Design Philosophy

LTS Search should feel:

* Scholarly but modern
* Calm and focused
* Minimalistic
* Slightly warm rather than purely technical
* Suitable for humanities + science communities

---

# Core Palette

## Primary Blue

```css
--primary-900:#0A3154;
--primary-800:#0F4C81;
--primary-700:#2B6EA6;
--primary-600:#4F89C5;
--primary-500:#73A5DE;
```

Meaning

* 900 → navbar
* 800 → buttons
* 700 → links
* 600 → hover
* 500 → focus ring
